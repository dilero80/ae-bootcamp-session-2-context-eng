# Functional Requirements

The TODO app shall support the following task-management capabilities:

1. **Due dates:** Users can add a due date to a task.
2. **Editing:** Users can edit an existing task.
3. **Ordering:** The app displays dated tasks by due date in ascending order, followed by undated tasks. Tasks with the same due date are ordered by creation time and then ID in ascending order.
4. **Deletion:** Users can delete a task.
